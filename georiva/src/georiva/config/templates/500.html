{% comment %} The one error page that extends nothing. Rendered by Django's stock `server_error`, which passes an empty context: no `request`, no context processors, no settings. So this page must not extend a shell, must not `{% load %}` anything, must not call `{% static %}` and must name no variable — anything it depended on could be the very thing that broke. The brand colours are inlined from `--gr-*` in `static/css/georiva.css` and have to be updated by hand if those change; that is the price of a page that renders when the stylesheet does not. Deliberately not split between the admin and public planes the way 403 and 404 are.
